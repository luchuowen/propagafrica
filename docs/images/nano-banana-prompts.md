# PropagAfrica — Nano Banana Pro image prompts

Twelve images. Each prompt below is complete on its own — copy one, paste it into Nano Banana Pro,
generate, save under the given file name, and drop it in the given folder. Nothing else needs to be
open.

## Before you start — read once

**Where the files go:** `propagafrica/src/assets/images/products/` for images 1–11, and
`propagafrica/src/assets/images/social/` for image 12. Astro converts them to AVIF and WebP at build
time, so save the originals as **PNG at the largest size offered**. Do not resize them yourself.

**Why every prompt sounds the same:** the whole point is that the twelve images look like one
photographic session by one photographer, not twelve stock pictures. The lighting, background and
camera language are identical on purpose. Do not vary them.

**Why there are no people, no farms and no branded packaging:** photographs of staff, premises or
labelled product would be claims about things that cannot be shown yet. Every drum and bottle here is
plain and unlabelled, and the site uses drawings where a label would otherwise appear. This is a
deliberate decision, not an oversight — do not prompt your way around it.

**If an image comes back wrong,** the usual culprits are a glossy plastic sheen, an artificial
background gradient, or objects at implausible relative sizes. Regenerate rather than accept; a single
plastic-looking frame will make the whole set read as generated.

## After you have generated them

In your Terminal, from the repo root:

```
ls src/assets/images/products/
```

You should see eleven files. Session 8 wires them up, writes the alt text and handles the conversion to
AVIF and WebP. Any image you have not generated simply will not appear — the layout is built to be
complete without them, so there is no rush and no placeholder to remove.
